    BGE 等向量模型不限于 Ollama 部署。只要服务提供 OpenAI 兼容向量接口或 Ollama 原生接口，本地和远程都可接入。此配置用于范本索引和语义检索，聊天模型不能替代向量模型。

    自动模式：/v1 或 /embeddings 结尾使用兼容接口；/api/embed 结尾或无路径的 11434 端口使用 Ollama，其余使用兼容接口。非默认端口的 Ollama 请手动选择。地址请填写服务提供的 API 基础地址（含所需的 /v1 等路径），也可填写完整向量接口地址。
