# 演示素材与操作

`雨夜来信.txt` 是为本公开版新生成的虚构短篇，不是从现有小说截取的内容。可作为导入和检索样例。

1. 启动工作台，在参考范本库导入该 TXT，等待向量索引完成（需要 Embedding 服务）。
2. 在独立范本检索输入：“用反复的小动作表现等待同伴时的焦虑”。查看命中片段、章节和原文；AI 精选需要配置 LLM。
3. 在“继续已有小说”中导入相同文件，建立知识库并人工核对人物、信封和求助信号等条目（需要 LLM）。
4. 查看卡片来源和关联；通过 MCP 查询寄信者，并展开原文依据。

人工核对参考：第一章的车票与手机动作体现等待；第三章许宁承认寄信。以上只是原文定位参考，不是程序实测输出或检索质量保证。
